HƯỚNG DẪN SỬ DỤNG
1. Mở index.html để xem website trên máy tính.
2. Thay số điện thoại, Zalo và địa chỉ trong index.html.
3. Thay danh mục, mô tả và sản phẩm mẫu bằng dữ liệu thật.
4. Để đưa lên mạng miễn phí: dùng GitHub Pages hoặc Cloudflare Pages.
5. Form hiện tại chỉ là mẫu minh họa; cần kết nối dịch vụ form hoặc tạo nút Zalo thực tế.
